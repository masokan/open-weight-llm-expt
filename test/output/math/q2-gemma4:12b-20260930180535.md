$$F(x) = \int f(x) \, dx = \frac{1}{2} \left( \int

\right)$$

use **u-substitution**:
*   Let $u = \sin(x)$.
*   Then, $du = \cos(x) \, dx$.

Using the power rule for integration ($\int u^n du =

$$2u^{1/2} = 2\sqrt{\sin(x)}$$

$$2\sqrt{v} = 2\sqrt{\ln(x)}$$

$$F(x) = \frac{1}{2} \left( 2\sqrt{\sin(x)} + 2\sqrt{\ln(x)} \right) + C$$
