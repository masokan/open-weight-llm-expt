of the form $x^2 + 3y^2$, we can use an algebraic approach.

### Proof

Let the two numbers be:
1.  $N_1 = a^2 + 3b^2$
2.  $N_2 = c^2 + 3d^2$

where $a, b, c,$ and $d$ are integers. We want to show that their product
$N_1 \cdot N_2$ can be expressed in the form $x^2 + 3y^2$ for some
integers $x$ and $y$.

#### Method 1: Algebraic Expansion
First, we multiply the two expressions:
$$(a^2 + 3b^2)(c^2 + 3d^2) = a^2c^2 + 3a^2d^2 + 3b^2c^2 + 9b^2d^2$$

We can group the terms to attempt to form a square. Notice that $9b^2d^2$
is equal to $(3bd)^2$. We can rewrite the expression as:
$$a^2c^2 + 3a^2d^2 + 3b^2c^2 + (3bd)^2$$

To group these into a form $x^2 + 3y^2$, we need to find values for $x$
and $y$. Let's test the construction:
$$x = ac - 3bd$$
$$y = ad + bc$$

Now, let’s expand the expression $(ac - 3bd)^2 + 3(ad + bc)^2$:
1.  Expand $(ac - 3bd)^2$:
    $$(ac - 3bd)^2 = a^2c^2 - 6abcd + 9b^2d^2$$
2.  Expand $3(ad + bc)^2$:

3b^2c^2$$

Now, add the two results together:

The $-6abcd$ and $+6abcd$ terms cancel out:
$$a^2c^2 + 9b^2d^2 + 3a^2d^2 + 3b^2c^2$$

$$a^2(c^2 + 3d^2) + 3b^2(c^2 + 3d^2) = (a^2 + 3b^2)(c^2 + 3d^2)$$

$$N(x + y\sqrt{-3}) = (x + y\sqrt{-3})(x - y\sqrt{-3}) = x^2 - (-3y^2) =

$$N(\alpha) = a^2 + 3b^2$$
$$N(\beta) = c^2 + 3d^2$$

$$\alpha\beta = (a + b\sqrt{-3})(c + d\sqrt{-3}) = (ac - 3bd) + (ad +

$$N(\alpha\beta) = (ac - 3bd)^2 + 3(ad + bc)^2$$

$$(a^2 + 3b^2)(c^2 + 3d^2) = (ac - 3bd)^2 + 3(ad + bc)^2$$
